# BDO Ping Monitor (黒い砂漠 サーバーPing測定ツール)

[日本語 (Japanese)](README.md) | [English](README_en.md)

![スクリーンショット](ss.png)

PC版「黒い砂漠（BDO）」の特定サーバーへのネットワーク遅延（Ping値）を、リアルタイムで測定・可視化する非公式アプリケーションです。
主にPvPコンテンツ等で利用される特定のチャンネル（例：マルニ2chなど）が「本当に重いのか（ラグが発生しているのか）」を客観的な数値として確認・検証する目的で作成されました。

## 特徴
- **リアルタイム測定:** 約5秒間隔でTCP接続テストを行い、Ping値を継続的に表示・グラフ化します。
- **軽量・インストール不要:** Tauriフレームワークを利用しており、実行ファイル（`.exe`）単体で動作します。
- **カスタムサーバー対応:** 同梱の `servers.txt` を編集することで、任意のサーバーをセカンダリサーバーとして追加し、同時に測定することが可能です。

## 使い方（一般ユーザー向け）

GitHubの [Releases](../../releases) ページから最新の `BDO-Ping-Monitor-Portable.zip` をダウンロードし、解凍してください。
インストールは不要です。フォルダ内の `bdo-ping-monitor.exe` を実行するだけで起動します。

### カスタムサーバーの追加・変更（servers.txt）
`bdo-ping-monitor.exe` と同じフォルダにある `servers.txt` を編集することで、測定対象のサーバーを自由に変更・追加できます。

**仕様:**
- **1行目**に記述したサーバーがアプリ上部のメイン画面（Main）に表示されます。海外サーバーをメインにしたい場合は1行目を書き換えてください。
- **2行目以降**に記述したサーバーは、アプリ下部のサブ画面（Sub）のドロップダウンリストに追加されます。

**記述例:**
```text
# 黒い砂漠 カスタムサーバーリスト
# 書式: サーバー名:IPアドレス
malni-2ch: 20.222.139.220
Valencia-2ch: 172.207.217.188
Valencia-3ch: 20.78.237.149
```

### サーバーIPの調べ方
自分が遊んでいるサーバー（チャンネル）のIPアドレスが分からない場合は、Windows標準の「リソースモニター」で簡単に調べることができます。

1. 黒い砂漠を起動し、測定したいサーバーにログインします。
2. `Windowsキー` を押し、`resmon` と入力して **リソースモニター** を開きます。
3. **ネットワーク** タブを開きます。
4. 「ネットワーク活動を伴うプロセス」から `BlackDesert64.exe` を探し、左側のチェックボックスを入れます。
5. 下の **TCP 接続** の項目を見ます。
6. **リモートポート** が **`8889`** になっている接続を探してください。それが現在繋がっているゲームサーバーで間違いありません。
7. その **リモートアドレス** (IPアドレス) をコピーして、`servers.txt` に記述してください。

## 開発者向け（ソースからのビルド手順）

このプロジェクトはRustとTauri(v2)を利用して構築されています。

### 前提条件
- [Rust / Cargo](https://rustup.rs/) がインストールされていること
- [Tauri v2の要件](https://v2.tauri.app/start/prerequisites/)（Visual Studio C++ Build Toolsなど）が満たされていること

### ビルド方法

1. リポジトリをクローンします。
2. `src-tauri` ディレクトリに移動します。
```bash
cd src-tauri
```
3. リリースビルドを実行します。
```bash
cargo build --release
```
4. `src-tauri/target/release/bdo-ping-monitor.exe` が生成されます。
